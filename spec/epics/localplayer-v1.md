# LocalPlayer v1: a fast, simple, native macOS audio player

Native Swift macOS 26 player for local mp3/wav/m4a files with playlists, AppleScript parity and Sparkle updates. Source of truth: docs/prd.md and docs/tech-architecture.md. Open questions in the PRD (launch cold/warm definition, play latency, UI element list, Liquid Glass surfaces, accessibility, first slice) are not decided and must not be invented by implementers.

**Position:** 1 of 1
